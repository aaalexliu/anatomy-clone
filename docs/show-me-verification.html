Verify the claim, not the stack

Several prototypes can run. One exam scores all of them. A prototype never grades itself.

Fixed
  • Same four exam items for every prototype.
  • Held-out evidence. A second tracker, or labels written before the run.
  • Each score is pass, fail, or abstain.
  • A negative control must fail.
Open
Skeleton: OpenSim, SKEL, other
Tracker: WHAM, HMR, OpenCap, other
Muscles: moment-arm, static opt, learned
Motion: video retarget, Moco, scripted isolate
Draw: lines, fusiform, volume

Swap any slot. The report schema stays.

If playback is "the track, replayed," scoring it against that same track always passes. That test is illegal. The driving track and the scoring track must differ.

Four exam items

Item What we claim Score that matters Ignore
Biceps, triceps, glute max Isolate plays the joint that muscle can move Moment-arm sign vs the action table Video likeness
Squat, person in frame Replay stays on that person, vasti and glute max do the work Joint path vs held-out track, then muscle-role overlap Skin shading
Face pull, person in frame Rear deltoid, cuff, mid and lower trap, not a lat row Muscle-role overlap. Scapula may abstain A pretty scapula we did not see
Rotator-cuff couple Subscapularis opposes infraspinatus and teres minor Line-of-action directions Pose match to the M&M clip

Starting gates

Gates for ranking prototypes. Not clinical truth. Tune them after two prototypes exist.

ScorePassAbstain
Legality No frame outside a hard joint limit or coupler That joint has no limit in this model
Joint path Mean error under 10° on visible major joints, none over 20° Under 70% of major joints visible, mirror, cropped limbs
Muscle role Top-5 overlap at least 0.6, no prime mover with the wrong sign Load direction unknown
Negative control A lat pulldown labeled "face pull" must fail muscle-role The control clip is too messy to trust

What a report looks like

Illustrative, not a measured run. Two prototypes, one exam.

Prototype A

Video retarget + moment-arm paint

Squat joints pass Squat roles pass

Face pull roles fail Scapula abstain

Cuff couple pass Negative control fails, as required

Prototype B

Same retarget + static optimization

Squat joints pass Squat roles pass

Face pull roles pass Scapula abstain

Cuff couple pass Negative control did not fail

A can draw a squat. It cannot yet tell a face pull from a row. B paints the face pull, but it also paints the decoy, so it is not trusted. Neither wins the whole card. That is the point of leaving more than one prototype alive.
